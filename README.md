## 🧠 What is PWC?

PWC (Prigid World Cloud) aims to be the **next-generation decentralized cloud**—where AI, security, edge computing, and sustainability are first-class citizens.

Think of it as a future-proof cloud made:
- **By developers, for developers**
- **Open to everyone across the globe**
- **Modular, composable, and community-driven**
- **Built with the values of trust, innovation, and transparency**

We’re **not a company** — we’re a **movement** to create a programmable cloud for the people.

---

## ✨ Why Are We Building This?

The world is changing. Centralized clouds are not enough for:
- The explosion of edge devices
- The need for federated learning
- Global data privacy and compliance
- Developer empowerment across continents

PWC will be a platform where:
- Developers deploy apps across regions or planets 🌍🚀
- Communities run their own sovereign clouds
- Open-source wins over vendor lock-in

## 📦 Planned Tech Stack

> *(Still open for community input)*

- **Languages**: Rust, Go, TypeScript, Python  
- **Orchestration**: Kubernetes, Nomad  
- **AI Layer**: HuggingFace, LangChain, AutoML  
- **Networking**: LibP2P, QUIC, IPFS  
- **Security**: Zero Trust, Encryption-at-rest, OpenID  
- **UI**: Next.js, TailwindCSS, ShadCN  
- **Infra-as-Code**: Pulumi or Terraform
